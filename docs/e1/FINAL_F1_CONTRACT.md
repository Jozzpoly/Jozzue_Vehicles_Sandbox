## T1 operations

Only the existing two-point `rigid-link` / `telescopic-damper` participants qualify.
Second Connect requires the source point to be detached and the other point to
have exactly one point relation, currently satisfied. No extra incident relations
or ambiguous anchors qualify. Otherwise Connect retains C1 behavior, explicitly
reported; no automatic recovery is attempted.

The qualifying operation rotates the current endpoint vector toward the explicitly
selected target, translating the pose to preserve the other endpoint's **current
world position**, including when it is not the local origin. Own geometry and all
other participants are unchanged. A normal relation is added; length mismatch can
leave the new relation violated. Zero target span does not invoke completion.

FIT preserves the explicitly selected, uniquely connected satisfied point in
world space and moves only the opposite local endpoint along the current local
line to the target distance. It does not rotate or translate the participant,
repair arbitrary misalignment, alter relations, or move another participant.
Both endpoints must each have exactly one point relation; ambiguous cases do not
invoke T1 FIT. Both-already-exact is a no-op.
