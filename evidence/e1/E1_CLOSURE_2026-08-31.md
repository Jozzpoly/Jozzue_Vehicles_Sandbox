## Portable knowledge — not prescribed architecture

- A short authored edit → causal PLAY → exact BUILD recovery loop had bounded
  technical and Owner value in Causal Spine. Technical reachability is not an
  adequate proxy for the quality of structural construction.
- With the same E1 references/relations, changing operation consequences can
  remove manual registration in a two-point assembly. Preserving an already placed
  anchor deserves explicit attention in future real use cases; it need not imply
  richer sockets, a generic solver or continuous adaptation.
- Separating Connect's pose change from an explicit geometry operation is feasible
  here without persistent endpoint roles. This does not mandate two separate UI
  commands, this FIT grammar, or this reference model in next-gen JV.
- Test oracle assembly, ambiguous target identity, task understanding, presentation
  and operation burden can obscure a representation question. Keep them separate
  from Owner feel and mechanical/product acceptance.
