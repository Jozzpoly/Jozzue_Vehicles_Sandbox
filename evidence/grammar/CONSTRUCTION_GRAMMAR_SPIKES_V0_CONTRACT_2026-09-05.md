# Construction Grammar Spikes V0 — pre-verdict contract — 2026-09-05

Status: **INTERACTION / EXPERIENCE PROTOTYPE — NO PHYSICAL-CAUSALITY CLAIM**

## Central unknown

Rep4 proved materially richer causal mechanics but the Owner still experienced the apparatus as a pre-authored laboratory mechanism with editable coordinates.

The next uncertainty is therefore not another suspension relation. It is:

> **Which direct interaction grammar begins to feel like constructing/reconstructing a mechanism rather than tuning a fixed topology?**

## Why this is intentionally not physics-integrated

The project already owns qualified causal donor capital from Rep2/Rep4. Rep4 also showed that fully hardening an interaction family before Owner value is known is expensive.

This spike therefore isolates look-and-feel / construction-role questions. It may show immediate visual adaptation, but it must not present its links as a validated physical mechanism.

The UI must visibly state that this is an interaction prototype with no physics claim.

## Shared scene

Both variants use the same small wheel-corner workbench:

- fixed chassis reference;
- wheel/hub reference;
- several visible but unobtrusive connection sockets;
- generic adaptive rigid link as a deliberate construction primitive;
- the real `Asset_Dumper.gltf` donor for a semantically richer component.

Generic link geometry is not a placeholder substitute for a recovered component; the adaptive point-to-point link itself is the interaction object under test.

## Variant A — gesture-first connect-by-drag

- choose relation kind (`Link` or `Damper`);
- pointer-down on one socket;
- drag through space;
- release on another socket to create the relation;
- relation appears immediately between endpoints.

Question: does direct endpoint-to-endpoint drawing feel fast/natural enough to become a core construction gesture?

## Variant B — tool-first endpoint placement

- choose `Add Link` or `Add Damper` first;
- click endpoint A;
- click endpoint B;
- component/relation appears between them.

Question: is explicit component/tool intent clearer and less error-prone than gesture-first construction?

## Shared topology operations

Both variants must support:

- create relation;
- delete selected relation;
- reconnect either endpoint to another socket;
- clear construction;
- restore the same example construction;
- undo recent topology mutation.

This is the minimum qualitative step beyond Rep4. The Owner must be able to produce a meaningful relation graph that was not fully encoded by the experiment author.

## Visual / interaction principles

- sockets become salient in construction context without covering the scene in large debug markers;
- selected relation is obvious;
- direct actions have immediate visible consequence;
- destructive/topology actions are quickly reversible;
- weird but finite connection graphs are allowed;
- no hidden automatic correction toward a preferred suspension topology;
- Orbit camera remains available on empty-space drag.

## Machine preflight — intentionally lightweight

Before Owner comparison require only:

- TypeScript/Vite production build PASS;
- real Chromium loads the spike without page/console errors;
- both grammar modes can create a relation;
- real donor damper can be created between arbitrary tested sockets;
- undo/delete/reconnect are reachable;
- mode switching/reset remains usable;
- fullscreen/viewport interaction is not obstructed.

Do not run Rep4 physics/causal regression merely to qualify this interaction-only spike.

## Owner questions

Compare the variants primarily on:

- which one feels more like building something rather than operating an editor abstraction;
- whether creating/removing/reconnecting relations produces materially more agency than Rep4 hardpoint manipulation;
- whether the connection points are understandable without being visually obnoxious;
- whether generic link + real damper already suggests a useful construction language;
- whether either grammar deserves a causal integration experiment.

Do not ask about vehicle/suspension feel.

## Natural STOP

STOP after the first comparative Owner hands-on.

If neither variant is materially better than Rep4, discard both and reselect the interaction problem.

If one earns a real positive signal, freeze that grammar only as a candidate and design the smallest separate integration specimen against qualified Rep4/Rep2 mechanics. Do not infer final component/data/topology architecture from this spike.
